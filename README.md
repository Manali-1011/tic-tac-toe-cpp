# How to Run the Tic Tac Toe Game

### 1️⃣ Install a C++ Compiler

Make sure you have a C++ compiler installed:

* **Windows:** Install MinGW or use Dev C++ / CodeBlocks
* **Mac:** Install Xcode Command Line Tools
* **Linux:** Usually pre-installed (g++)

To check if installed, open Terminal/Command Prompt and run:

```
g++ --version
```

---

### 2️⃣ Download or Clone the Project

Option A: **Download the ZIP**

* Click the green "Code" button
* Select **Download ZIP**
* Extract it to your computer

Option B: **Clone using Git**

```
git clone https://github.com/Manali-1011/tic-tac-toe-cpp.git
```

---

### 3️⃣ Open Terminal / Command Prompt

Navigate to the folder where the file is located:

```
cd tic-tac-toe-cpp
```

---

### 4️⃣ Compile the Game

Run this command:

```
g++ tictactoe.cpp -o game
```

This will create an executable file named **game**

---

### 5️⃣ Run the Game

#### On Windows:

```
game.exe
```

#### On Mac / Linux:

```
./game
```

---

### 🎉 Now Play!

The game will open in the terminal.
Players take turns entering positions and the game will announce the winner or a draw.
